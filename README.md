# 📊 Sales Data Analysis Dashboard

## 📌 Project Overview
This project analyzes sales data to identify trends, top-performing products, and revenue patterns.

## 🛠 Tools Used
- Excel (Pivot Tables, Data Cleaning)
- Power BI (Dashboard, KPIs)

## 📈 Key Insights
- Top 5 products contribute majority of revenue
- Monthly sales trends identified
- Category-wise performance analyzed
